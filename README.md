# 叡研空間設計｜網站與程式碼

叡研空間設計（Akiraken Space Design）的網頁工具與程式碼，集中放在這個倉庫，由 GitHub Pages 對外發布。

## 目前的專案

| 資料夾 | 內容 | 公開網址 |
|---|---|---|
| `quiz/` | 「測一測你適合的裝修風格」測驗（臉書貼文、LINE 選單使用） | `/quiz/` |

之後新增的專案，一個專案放一個資料夾，例如 `quiz/`、`tool-xxx/`。

## 如何更新

1. 修改對應資料夾裡的 `index.html`。
2. 提交（commit）並推送到 `main`。
3. 約 1 分鐘後，網址上的內容會自動更新。

## 這是公開倉庫，請注意

GitHub Pages 免費版只能使用公開倉庫，裡面的所有檔案任何人都看得到。

**可以放**：給大眾使用的網頁、程式碼、公開用的圖片。

**不要放**：業主報告、廣告成效數字、客戶姓名或地址、報價、未發布的貼文草稿、帳號密碼或金鑰。這些資料留在本機的叡研資料夾，不要放進這個倉庫。
